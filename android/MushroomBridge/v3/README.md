# Mushroom Bridge 3

Offline Android BLE logger for two SwitchBot Meter Plus sensors. Records paired IN/OUT measurements locally to one CSV table and shares it through the Android share sheet (for example directly to ChatGPT). No GitHub token or cloud upload is required.

Build identity: applicationId `cz.mushroomfarm.bridge.v3`, versionCode `3`, versionName `3.0.0`, so it can be installed alongside the earlier debug build even when the signing key differs.
